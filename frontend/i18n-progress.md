# iBlog 国际化改造进度

目标：公开端和管理端支持 zh-CN/en-US 切换；后端返回稳定错误码，前端按当前语言显示文案；不翻译数据库中的文章和用户内容。

## 阶段

- [x] 1. 共享语言模块和语言持久化
- [x] 2. 公开端主要 UI 文案（仍需完成剩余细节文案审计）
- [x] 3. 管理端 UI 文案（用户内容字段保持原样；剩余默认页脚内容不参与翻译）
- [x] 4. 后端错误响应只包含稳定 code；前端统一映射当前语言
- [x] 5. SEO、无障碍文案和边界检查
- [x] 6. 完整验证和交付报告

## 约束

- 不改变文章、摘要、Markdown、关于内容和友情链接等用户数据。
- 不引入数据库多语言结构。
- 公开端和管理端共用语言包与语言选择。
- 中文作为 fallback，缺失英文翻译不能显示空白。
- 每阶段完成后运行对应格式检查或构建。
