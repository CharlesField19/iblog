# iBlog v1.1.2 SEO and SSR Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or execute it inline in this session, task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make all public iBlog pages return crawlable HTML with correct metadata, structured data, feed output, and real HTTP status codes while retaining Go + SQLite + Vue 3 and deferring image features.

**Architecture:** The Go server will render public pages from SQLite through `html/template`, using the existing Vue app only for client interaction after the initial document is available. API and admin behavior remain unchanged. Public route handling will become explicit so article, redirect, not-found, and SPA admin routes cannot collapse into a 200 homepage.

**Tech Stack:** Go 1.23+, SQLite, `html/template`, existing Markdown sanitizer, Vue 3, Vite, Tailwind CSS v4.

**Spec:** `docs/plans/2026-11-08-v1.1.2-seo-ssr.md`

## Global Constraints

- Do not migrate to Next.js, React, or Node runtime.
- Defer article cover upload, image processing, WebP/AVIF conversion, and image-specific settings.
- Published content only may appear in SSR pages, sitemap, JSON-LD, or RSS.
- Existing slug aliases must redirect with 301; existing slugs must not be batch-renamed.
- Keep the current API contracts backward compatible.
- Preserve the current Markdown sanitizer and CSP/security headers.
- Keep production artifacts outside `src/`; runtime files remain under `/opt/vps-services/openchamber/data/blog/`.

## Review Focus

- Draft and nonexistent article paths must return HTML 404, never SPA 200; covered by SSR route tests.
- Alias slugs must return 301 to the canonical current slug; covered by route tests.
- Search/filter pages must not become indexable duplicate pages; covered by metadata tests.
- User-controlled title, summary, Markdown, and settings must not break HTML, JSON-LD, or RSS; covered by escaping/sanitization tests.
- SSR must not increment views as if every crawler request were a human view; covered by view-count tests.
