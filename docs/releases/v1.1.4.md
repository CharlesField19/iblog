# iBlog v1.1.4

## 前端体验微调

- 首页首屏保留标题、标语和社交入口，最新文章放在首屏下方，继续支持向下浏览。
- 文章页标签改为单行横向滚动，避免标签过多时把文章列表挤出首屏。
- Markdown 代码块增加服务端语法高亮，并允许过长代码行在代码块内换行。
- 调整首页标语的字体布局，减少中英文切换时的视觉位移。
- 为卡片、搜索框和代码块增加连续曲率的渐进增强；不支持的浏览器继续使用普通圆角。

## 依赖与兼容性

- 使用 `github.com/yuin/goldmark-highlighting/v2` 生成代码高亮 class。
- 保持 Go SSR、Vue 3、Tailwind CSS 和现有 Markdown 安全过滤逻辑不变。
- Git tag 使用标准格式 `v1.1.4`，GitHub Release 标题使用 `iBlog v1.1.4`。

## 验证

- Go 全量测试与 `go vet`。
- 前端 typecheck、格式检查、i18n 测试和构建。
- Docker 构建及 Docker e2e。
