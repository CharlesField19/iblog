# iBlog v1.1.2

## SEO 与服务端渲染

- 公开首页、文章列表、文章详情、关于和友链页面改为 Go 服务端渲染。
- 文章页输出标题、摘要、canonical、Open Graph、Twitter metadata、BlogPosting 和 BreadcrumbList JSON-LD。
- 草稿、已删除文章和未知公开路径返回 HTML 404；旧 slug 保留 301 跳转。
- 搜索页使用 `noindex,follow`，分页列表保留对应 canonical，新增 `/feed.xml` RSS。
- SSR 初始数据嵌入 `__IBLOG_INITIAL__`，Vue 首次接管时避免重复读取公开 API。

## 内容与兼容性

- 新文章未填写 slug 时按标题生成语义化 slug，重复 slug 自动添加序号；已有 slug 不批量修改。
- 新文章 slug 仅接受小写字母、数字和连字符；已有旧 slug 可继续保留，修改时旧地址自动成为 alias。
- 文章 GET 不再增加浏览量，客户端通过 `POST /api/v1/articles/{slug}/view` 记录浏览量。
- 保留 Go + SQLite + Vue 3 架构和现有 API；图片封面、上传、处理、WebP/AVIF 继续暂缓。

## 验证

已完成 Go 全量测试与 vet、前端 typecheck/格式/i18n/build、Docker 构建及 Docker e2e。e2e 覆盖原始文章 HTML、JSON-LD、404、草稿隔离和 RSS；Cloudflare/Baiduspider 验证清单见 [`docs/seo-verification.md`](../seo-verification.md)。

发布前仍需在 Cloudflare 控制台确认 Managed robots content 不会注入 `Baiduspider Disallow: /`，并由站点所有者完成线上验收。
