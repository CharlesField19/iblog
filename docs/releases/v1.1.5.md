# iBlog v1.1.5

## 服务端结构

- `cmd/blog/server.go` 按职责拆分为 `articles.go`、`auth.go`、`cache.go`、`friends.go`、`http.go`、`routes.go`、`settings.go`、`tags.go`、`views.go`，行为保持不变。
- 请求处理增加读取/写入/空闲超时，并对请求体设置上限。
- Markdown 预览、文章批量操作和设置写入沿用原有校验规则。

## 安全与配置

- 登录失败按来源 IP 计数，连续 5 次失败后 10 分钟内返回 `429`。
- Cookie 会话继续使用 `HttpOnly`、`SameSite=Lax`；HTTPS 部署追加 `Secure` 与 HSTS。
- 启动校验拒绝“`https://` 站点地址 + 非安全 Cookie”等矛盾组合。
- 新增启动告警：开启 `BLOG_TRUST_PROXY=true` 但未设置公开地址、且未启用安全 Cookie 时，日志提示生产环境必须配置 `BLOG_PUBLIC_ORIGIN=https://...` 与 `BLOG_COOKIE_SECURE=true`。
- Compose 默认值改为可用的本机预览配置（`BLOG_COOKIE_SECURE=false` + loopback 地址），生产要求显式覆盖。
- 文档补充：使用宿主目录绑定挂载 `/data` 时，目录属主必须为 `10001:10001`。

## 构建与检查

- CI 与发布流程固定 Go `1.26.x`，`govulncheck` 固定为 `v1.9.0`。
- CI 增加 `npm audit`、`go test -race` 和漏洞扫描步骤。
- 升级 `github.com/yuin/goldmark` 到 `v1.7.17`，修复 `GO-2026-5320`（Markdown 渲染 XSS）。
- 升级 Go 到 `1.26`、`golang.org/x/net` 到 `v0.62.0`，修复标准库与 HTML 解析的可达漏洞；`govulncheck` 复扫为 0。
