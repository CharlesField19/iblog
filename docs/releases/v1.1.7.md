# iBlog v1.1.7

## 加载状态

- 新增统一的加载组件，提供页面级、卡片级和按钮内联三种形态。
- 文章详情、登录页安装检查、标签管理、友链管理、关于管理、站点设置和文章编辑器改为居中加载，不再在内容左上角显示一行文字。
- 加载动画延迟 200ms 出现，接口较快时不会闪烁；系统开启“减少动态效果”时停止旋转。
- 加载区域使用 `role="status"` 与 `aria-live="polite"`，读屏会播报当前状态。
- 首页、文章列表、友链页和文章管理列表继续使用骨架屏，保持内容占位、避免布局跳动。
- 加载更多与保存、登录、创建、添加等按钮改为内联小圆环，按钮尺寸保持稳定。
