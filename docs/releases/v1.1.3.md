# iBlog v1.1.3

## 安全依赖升级

- 将间接依赖 `golang.org/x/net` 从 `v0.26.0` 升级到 `v0.55.0`，覆盖 GitHub Dependabot 报告的 3 个 Moderate 安全问题。
- 同步升级 `golang.org/x/sys` 到 `v0.45.0`。
- Go 模块版本升级到 Go 1.25，Docker 构建镜像同步升级到 `golang:1.25-alpine`。
- 保持 Git tag 使用标准格式 `v1.1.3`，GitHub Release 标题统一使用 `iBlog v1.1.3`。

## 验证

- Go 全量测试与 `go vet`。
- 前端 typecheck、格式检查、i18n 测试和构建。
- Docker 构建及 Docker e2e。
